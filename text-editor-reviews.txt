-------------------------------
----- TEXT EDITOR REVIEWS -----
-------------------------------

Here is a list of reviews for some of the best text editors for Linux.

------------------------------------------
--- VIM / NEOVIM ---

Pros:
+ The Number One text editor for Linux
+ Very Popular and widely available across several platforms
+ Very large number of controls and commands thanks to Modal Editing
+ Easy configuration using Vimscript (Vim) and Lua (NeoVim)

Cons:
- Can be difficult for beginners and first time users

------------------------------------------
--- EMACS ---

Pros:
+ Very popular and widely available
+ Allows editing using Vi modal commands, using Viper or Evil-Mode

Cons:
- Can be difficult for beginners and first time users
- Has multiple and complex keybinding controls to perform a single command

------------------------------------------
--- NANO ---

Pros:
+ Very popular and widely available
+ Very easy for beginners and first time users

Cons:
- Non-Standard and limited keybindings
- Unsuitable for use as a code editor for IDE productivity

------------------------------------------
--- HELIX ---

Pros:
+ Uses Model Editing, suitable for Vim/Neovim users

Cons:
- Commands are not 100% compatible with Vim/NeoVim
- Configuration is limited to a few TOML files, and does not support plugins

------------------------------------------
--- MICRO ---

Pros:
+ Uses IBM Common User Access standard for keybindings
+ Targets Nano users for a better editing experience
+ Uses Lua for plugins and configuration

Cons:
- Should be used within a terminal emulator from X or Wayland

------------------------------------------
--- FRESH ---

Pros:
+ One of the newest text editors (Created Late 2025 / Early 2026)
+ Uses IBM Common User Access standard for keybindings
+ Targets Nano and Micro users for a better editing experience
+ Allows editing using Vi modal commands

Cons:
- As this is a new editor, expect a few bugs

------------------------------------------
