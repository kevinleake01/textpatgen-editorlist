-------------------------------
----- TEXT EDITOR REVIEWS -----
-------------------------------

Here is a list of reviews for some of the best text editors for Linux.

------------------------------------------
--- VIM / NEOVIM ---

https://www.vim.org/
https://neovim.io/

Pros:
+ The Number One text editor for Linux
+ Very Popular and widely available across several platforms
+ Very large number of controls and commands thanks to Modal Editing
+ Easy configuration using Vimscript (Vim) and Lua (NeoVim)

Cons:
- Can be difficult for beginners and first time users

------------------------------------------
--- EMACS ---

https://www.gnu.org/software/emacs/

Pros:
+ Very popular and widely available
+ Allows editing using Vi modal commands, using Viper or Evil-Mode
+ Easy configuration and plugins using Emacs Lisp (Elisp)

Cons:
- Can be difficult for beginners and first time users
- Has multiple and complex keybinding controls to perform a single command

------------------------------------------
--- NANO ---

https://www.nano-editor.org/

Pros:
+ Very popular and widely available
+ Very easy for beginners and first time users

Cons:
- Non-Standard and limited keybindings
- Unsuitable for use as a code editor for IDE productivity

------------------------------------------
--- NE (The Nice Editor) ---

https://github.com/vigna/ne

Pros:
+ Very easy for beginners and first time users
+ Uses IBM Common User Access standard for keybindings
+ Targets Nano users for a better editing experience

Cons:
- Not shipped by default on most Linux Distros

------------------------------------------
--- HELIX ---

https://helix-editor.com/

Pros:
+ Uses Modal Editing, suitable for Vim/Neovim users

Cons:
- Commands are not 100% compatible with Vim/NeoVim
- Configuration is limited to a few TOML files, and does not support plugins

------------------------------------------
--- MICRO ---

https://micro-editor.github.io/

Pros:
+ Uses IBM Common User Access standard for keybindings
+ Targets Nano users for a better editing experience
+ Uses Lua for plugins and configuration

Cons:
- Should be used within a terminal emulator from X or Wayland, because of problems with <Shift><Arrows>

------------------------------------------
--- FRESH ---

https://getfresh.dev/

Pros:
+ One of the newest text editors (Created Late 2025 / Early 2026)
+ Uses IBM Common User Access standard for keybindings
+ Targets Nano and Micro users for a better editing experience
+ Allows editing using Vi modal commands

Cons:
- As this is a new editor, expect a few bugs

------------------------------------------
--- LITE XL ---

https://lite-xl.com/

Pros:
+ Uses IBM Common User Access standard for keybindings
+ Uses Lua for plugins and configuration
+ Has an integrated file browser by default

Cons:
- Not shipped by default on most Linux Distros

------------------------------------------
--- CODE::BLOCKS ---

https://www.codeblocks.org/

Pros:
+ One of the best code editors if using C and C++
+ Uses IBM Common User Access standard for keybindings

Cons:
- Targets C and C++ programmers only

------------------------------------------
--- GEANY ---

https://www.geany.org/

Pros:
+ The Number One IDE code editor using the GTK GUI Platform
+ Very easy for beginners and first time users
+ Uses IBM Common User Access standard for keybindings

Cons:
- None!  :-)

------------------------------------------
--- KDEVELOP / KATE / KWRITE ---

https://kdevelop.org/
https://kate-editor.org/
https://apps.kde.org/kwrite/

Pros:
+ The best IDE code editors using the QT GUI Platform
+ Very easy for beginners and first time users
+ Uses IBM Common User Access standard for keybindings
+ Allows editing using Vi modal commands

Cons:
- None!  :-)

------------------------------------------
--- LIBREOFFICE ---

https://www.libreoffice.org/

Pros:
+ The Number One Word Processor for Linux
+ Very easy for beginners and first time users
+ Uses IBM Common User Access standard for keybindings

Cons:
- You cannot do IDE code editing, because this is a Word Processor!  ;-)

------------------------------------------
