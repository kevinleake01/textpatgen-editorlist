Here is a quick review of some of the Rust Text and Code Editors. It should be
noted that not all of the editors can be reviewed, as there are too many to
list here.
-------

HELIX: https://helix-editor.com/
FRESH: https://getfresh.dev/

Helix and Fresh are the best text and code editors written in Rust, and they are
recommended for general use.
-------

VLE: https://github.com/tuffy/vle

VLE (Very Little Editor) places the cursor in the middle of the screen, and this
allows you to do editing while the screen automatically scrolls.
-------

AD: https://github.com/sminez/ad
AMP: https://amp.rs/
PEPPER: https://vamolessa.github.io/pepper/

Ad, Amp, and Pepper use Modal editing similar to Vi/Vim, but users have reported
that the commands are not 100% compatible. For example, to save the file in Vim
is ':w', but in Pepper it is ':save'.
-------

KIBI: https://github.com/ilai-deutel/kibi
KIRO-EDITOR: https://github.com/rhysd/kiro-editor
KILO-RS: https://github.com/khadiwala/kilo-rs

Kibi, Kiro-Editor, and Kilo-rs are based on the KILO Editor written in C, and
very small, coming in at approx 1024 lines of code. However, many users have
reported these editors to be very basic, and many features are missing.
-------

ZEE: https://github.com/zee-editor/zee

The Zee Editor uses Emacs keybindings for commands.
-------

Whatever Rust Text or Code editor you use, it is important you first test your
editing skills using the Text Pattern Generator to make sure there are no
problems, and everything is OK. For links to the Text Pattern Generator:

TEXTPATGEN: https://codeberg.org/kevinleake01/textpatgen
TEXTPATGEN-GOLANG: https://codeberg.org/kevinleake01/textpatgen-golang
TEXTPATGEN-QUICKSCRIPTS: https://codeberg.org/kevinleake01/textpatgen-quickscripts
